## Quick Search Guide
- **By Keyword**: Use `Ctrl + F` to search for keywords like `apriori`, `knn`, `kmeans`, `titanic`, `salary`, `cars`, etc.
- **By Examination Slip**: Jump directly to any slip number (Slip 1 to Slip 25).

- **By CLI Search**: Run `python find_program.py "<paste your question here>"` to get the top 5 closest matches instantly.
